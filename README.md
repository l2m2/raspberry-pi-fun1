# raspberry-pi-fun1

用一堆东方树叶小瓶子和树莓派，做一个能动、能变形的机器人。

## 要玩什么

手头攒了很多东方树叶的小瓶子。想法是把瓶子当成机器人的"骨节"，节与节之间用舵机连接，由树莓派统一控制，让它像蛇一样爬，或者拼成其他形态，类似"变形机器人"。

最终希望它**能自己移动**，不依赖插电。

## 路线

| 阶段 | 目标 |
|---|---|
| 1. 瓶子蛇 | 3 节瓶子 + 2 个舵机做小样，验证连接、瓶身强度和供电；再加长，跑出正弦波蠕动步态 |
| 2. 足式 | 瓶子当腿和躯干，做四足或六足 |
| 3. 可重组 | 每节模块都能独立连接、断开，真正"变形"（难度最高，放在最后） |

另一个可以试的方向是**气动软体**：PET 瓶耐压，配上气泵和电磁阀，可以做伸缩、弯曲的动作。

## 怎么做

**结构**
- 瓶身薄、易捏扁，力从**瓶口螺纹**和**套在瓶身外的夹具**上传，不直接在瓶身上固定舵机。
- 瓶口用 3D 打印的转接件（OpenSCAD 参数化建模），一头拧在瓶口上，一头装舵机。
- 瓶子内部可以装电池和线材，顺便当配重。

**电子**

```
树莓派 3B+
  └─ I2C ─> PCA9685 16 路舵机驱动板
              └─ SG90 / MG90S 舵机 × N

2 节 18650（7.4V）
  ├─> 5V 3A 降压 ──> 树莓派
  └─> 6V 5A 降压 ──> 舵机（PCA9685 V+）
  所有 GND 共地
```

- 舵机不能从树莓派的 5V 引脚取电，必须单独供电。
- 两节 18650 的直径和小瓶差不多，可以装进一节瓶子里当"电池舱"。

**软件**
- Python + `adafruit-circuitpython-servokit` 驱动 PCA9685。
- 蛇形步态：各关节按正弦波依次错开相位。

## 本地配置

树莓派的 SSH 信息放在仓库根目录的 `.env` 里（已被 git 忽略，不会提交）：

```
PI_HOST=<树莓派 IP>
PI_USER=<用户名>
PI_PASSWORD=<密码>
```
