# raspberry-pi-fun1

用一堆东方树叶小瓶子和树莓派，做一个能动、能变形的机器人。

## 要玩什么

手头攒了很多东方树叶的小瓶子。想法是把瓶子当成机器人的"骨节"，节与节之间用舵机连接，由树莓派统一控制，让它像蛇一样爬，或者拼成其他形态，类似"变形机器人"。

最终目标是做一个**巨型变形机器人**：能在几种形态之间切换，**能自己移动**，不依赖插电。

## 路线

| 阶段 | 目标 |
|---|---|
| 1. 瓶子蛇 | 3 节瓶子 + 2 个舵机做小样，验证连接、瓶身强度和供电；再加长，跑出正弦波蠕动步态 |
| 2. 足式 | 瓶子当腿和躯干，做四足或六足 |
| 3. 可重组 | 每节模块都能独立连接、断开，真正"变形"（难度最高，放在最后） |
| 4. 巨型变形 | 放大体型、增加关节，在几种形态之间按编排好的顺序切换 |

另一个可以试的方向是**气动软体**：PET 瓶耐压，配上气泵和电磁阀，可以做伸缩、弯曲的动作。

## 怎么做

**结构**
- 瓶身薄、易捏扁，力从**瓶口螺纹**和**套在瓶身外的夹具**上传，不直接在瓶身上固定舵机。
- 瓶口用 3D 打印的转接件（OpenSCAD 参数化建模），一头拧在瓶口上，一头装舵机。
- 瓶子内部可以装电池和线材，顺便当配重。
- 做大以后关节力矩成倍增加，瓶子只当外壳和"骨节"造型，内部要加骨架（3D 打印件或铝型材）承重。

**电子**

```
树莓派 3B+
  └─ I2C ─> PCA9685 16 路舵机驱动板
              └─ SG90 / MG90S 舵机 × N

2 节 18650（7.4V）
  ├─> 5V 3A 降压 ──> 树莓派
  └─> 6V 5A 降压 ──> 舵机（PCA9685 V+）
  所有 GND 共地
```

- 舵机不能从树莓派的 5V 引脚取电，必须单独供电。
- 两节 18650 的直径和小瓶差不多，可以装进一节瓶子里当"电池舱"。
- 树莓派当"大脑"，负责形态切换、动作编排、遥控，以后还有摄像头；舵机的 PWM 交给驱动板，不用树莓派直接输出。
- 舵机多了以后，PCA9685 可以改地址串联多块（每块 16 路）。

**做大以后的升级方向**
- **总线舵机**（如 STS3215）：所有舵机串成一条线接树莓派 UART，不用每个舵机单独拉线回主板；还能读回角度、负载、温度，变形中途卡住可以检测到。
- 承重关节换大扭矩舵机（MG996R 或更大），电源要按十几安的峰值电流重新设计。
- 可重组阶段可以考虑每个模块放一块 ESP32，由树莓派统一调度。

**软件**
- Python + `adafruit-circuitpython-servokit` 驱动 PCA9685。
- 蛇形步态：各关节按正弦波依次错开相位。

## 本地配置

树莓派的 SSH 信息放在仓库根目录的 `.env` 里（已被 git 忽略，不会提交）：

```
PI_HOST=<树莓派 IP>
PI_USER=<用户名>
PI_PASSWORD=<密码>
```
